# 焦煤期货日报

**资讯日期：2026年8月27日**  
**整理日期：2026年8月28日**  
**重点合约：JM2609、JM2701**  
**数据口径：调查类数据仅采用8月27日当天发布或当天最新市场状态；不使用上周及更早的铁水、钢厂盈利率、矿山/洗煤厂/焦企/钢厂库存等周度调查数据。**

---

## 报告摘要

8月27日焦煤期货重新大幅走强，近月JM2609明显强于主力JM2701。JM2609收于**1685.5元/吨**，较8月26日收盘1597元/吨上涨88.5元/吨，涨幅约**5.54%**；JM2701收于**1609元/吨**，较8月26日收盘1574元/吨上涨35元/吨，涨幅约**2.22%**。JM2609较JM2701升水扩大至**76.5元/吨**，近强远弱结构进一步强化。

两份合约的资金性质明显不同。JM2701成交量**1,040,547手**，仍是绝对主力合约；收盘后前20多头持仓合计**346,115手，日增26,803手**，空头持仓合计**294,443手，日增10,556手**，多头增仓明显快于空头，属于新增资金继续参与上涨。JM2609成交量仅**131,477手**，主要席位多空双方均明显减仓，价格大涨更多体现临近交割、现货资源偏紧、空头回补和交割品溢价。

基本面继续偏强。8月27日日度调研主产地煤矿20家，**14家稳价、5家涨价、1家降价，另有5家停产**；主产地安监仍严，停产煤矿恢复慢，复产矿井普遍存在“复产不复量”。焦炭第二轮提涨已经落地，继续为焦煤成本向下游传导提供支撑。

当天交割端出现重要变化：大商所新增**沧州黄骅港矿石港务有限公司**为焦煤指定仓库，同时将**天津港焦炭码头有限公司焦煤协议库容由15万吨扩大至20万吨**。该调整不会直接增加焦煤实物供应，但会提高仓单组织和交割便利度，降低近月合约的交割稀缺溢价和逼仓风险，对JM2609影响明显大于JM2701。

综合判断，8月27日焦煤仍处于**高位偏强、近端现实紧张主导**的行情。JM2609已逐步进入交割定价阶段，后续更应关注仓单和09—01价差；JM2701仍是判断中期资金情绪和未来供需预期的核心合约。

8月27日最大的盘面特征是**2609涨幅显著高于2701，但交易重心仍在2701**。2609的价格弹性越来越受到交割、仓单和近端现货影响，2701则更能代表市场对未来供需和资金预期的判断。

### 2. JM2609：近月大涨，交割属性增强

收盘后可核验的JM2609主要席位数据显示：

| 项目 | 持仓 | 日变化 |
|---|---:|---:|
| 前10多头 | **50,497手** | **-14,898手** |
| 前10空头 | **45,849手** | **-12,245手** |
| 前10多空差 | **+4,648手** | 较前日收窄 |

价格上涨超过5%，但多空双方都在明显减仓，说明2609当天并非典型的“新增资金追多”。

更合理的解释是：

**现货近端紧张 + 临近交割 + 空头回补 + 存量资金退出 + 流动性下降，共同放大2609价格。**

因此，2609后续应更多使用**交割逻辑**分析，而不能简单把其涨幅外推到整个焦煤市场。

## 二、主要资讯梳理

### 1. 供应端：复产仍慢，“复产不复量”延续

8月27日日度煤矿调研主产地煤矿20家：

| 状态 | 数量 |
|---|---:|
| 稳价 | **14家** |
| 涨价 | **5家** |
| 降价 | **1家** |
| 停产 | **5家** |

安监仍严，停产煤矿恢复偏慢，已复产煤矿多数仍存在实际产量恢复不足的情况。

**对焦煤影响：偏多。**

### 2. 蒙煤：供应仍紧，高价成交出现分化

8月27日甘其毛都主要煤种：

| 品种 | 价格（元/吨） |
|---|---:|
| 蒙5#原煤 | **1654** |
| 蒙5#精煤 | **1872** |
| 蒙4#原煤 | 1712 |
| 蒙3#精煤 | 1620 |
| 1/3焦原煤 | 1150 |

口岸通关缩量暂未明显缓解，资源仍偏紧，但整体成交表现一般。蒙5等高价资源接受度已经出现下降。

**对焦煤影响：现实偏多，边际降温。**

### 3. 焦炭端：第二轮提涨落地

焦炭第二轮提涨已经落地：

- 湿熄焦：**+100元/吨**
- 干熄焦：**+110元/吨**

焦煤成本继续向焦炭端传导，对焦煤现货形成支撑。

### 4. 交割端：新增黄骅港仓库，天津港焦煤库容扩容

大商所8月27日公告：

- 新增**沧州黄骅港矿石港务有限公司**为焦煤指定仓库；
- 天津港焦炭码头有限公司焦煤指定仓库协议库容由**15万吨扩大至20万吨**；
- 上述事项自即日起生效。

该政策不会直接增加全国焦煤供应，但会增加可以用于交割的仓储与物流通道。

#### 对JM2609

2609已经临近交割，09—01升水达到76.5元/吨，其中包含一定的近端现货紧张、可交割资源、仓单与库容以及临近交割的空头回补溢价。

新增交割库和扩大天津港库容有利于：

**提高空头组织交割能力 → 增加潜在仓单供给 → 降低逼仓风险 → 压缩2609额外交割溢价。**

因此对2609属于**较直接的边际利空**。

#### 对JM2701

2701距离交割仍较远，交割库扩容更多改变未来仓单组织预期。

因此对2701属于**中性偏空**，影响强度明显弱于2609。

## 三、价格驱动逻辑

1. **国内供应仍未有效恢复。** 日度调查继续显示停产和复产不复量，对焦煤偏多。
2. **2609大涨更多体现交割和现货逻辑。** 主要席位多空均明显减仓，追涨风险高于2701。
3. **2701是真正的资金主战场。** 前20多头增仓2.68万手，空头仅增1.06万手，短期偏多。
4. **09—01价差扩大。** 76.5元/吨升水反映近端紧张被高度定价，同时增加价差回落风险。
5. **交割库扩容压制近月稀缺溢价。** 对2609偏空，对2701影响较弱。
6. **焦炭提涨继续支撑焦煤。** 但若后续钢厂抵制提涨，焦企减产将形成需求负反馈。

---

## 四、风险点

1. 主产地实际复产加快——利空；
2. 甘其毛都通关恢复——利空；
3. 蒙煤高价成交继续转弱——利空；
4. 焦炭后续提涨受阻——利空；
5. 黄骅港、天津港新增交割能力转化为仓单——偏空2609；
6. 09—01价差快速收窄——偏空2609；
7. 2609临近交割流动性下降——双向放大波动；
8. 2701多头拥挤后集中平仓——偏空风险；
9. 安监继续收紧或新增停产——利多；
10. 成材无法承接煤焦上涨——中期利空。

---

## 五、综合判断

### JM2609：短期强势，但交割风险快速上升

2609收于1685.5元/吨，近月资源紧张仍然明显。

但主要席位多空同时减仓，说明合约已经进入较强的交割定价阶段。大商所同步增加焦煤交割仓库和天津港库容，将对近月仓单稀缺溢价形成压制。

**2609短期仍强，但不宜再单纯按趋势多头逻辑追涨。**

后续重点观察：

- 09—01价差；
- 焦煤仓单数量；
- 黄骅港与天津港新增交割能力是否实际使用。

### JM2701：高位偏强，仍是趋势判断核心

JM2701收1609元/吨，新增资金仍明显偏多。

短期关注：

- **第一支撑：1580—1600元/吨**
- **强支撑：1550—1560元/吨**
- **第一压力：1630元/吨**
- **上破后：1650元/吨附近**

供应恢复仍慢时，2701仍具备高位运行基础。

## 七、结论

8月27日焦煤期货继续强化近强远弱结构。JM2609收于1685.5元/吨，JM2701收于1609元/吨，09—01升水扩大至76.5元/吨。国内煤矿复产仍慢、蒙煤通关偏低和焦炭第二轮提涨继续构成现实支撑。

但2609与2701已经不能用同一套逻辑分析。2609主要席位多空均明显减仓，临近交割和现货紧张对价格影响越来越大；2701前20多头明显增仓，仍是新增资金和未来供需预期的主要交易合约。

8月27日大商所新增黄骅港焦煤交割库并扩大天津港焦煤库容，是对2609最重要的新变量。该政策不改变焦煤现实总供应，却可能增加仓单组织能力并压缩近月交割稀缺溢价。

因此后续研究重点应明确区分：

**2609看仓单、交割和09—01价差；2701看资金、供应恢复、蒙煤通关和焦炭需求。**

整体维持**高位偏强震荡**判断，但近月追涨风险已经明显高于主力远月。
